# Goto

Goto 是一个 Android 快捷跳转工具，用于集中管理常用应用、系统设置和网页入口。应用还提供局域网管理页面，方便在同一网络内通过电脑整理配置或触发手机操作。

## 主要功能

- 将常用应用固定到主页，以自适应网格展示。
- 进入调整模式后拖动应用排序，轻点应用可确认移除。
- 快速打开开发者选项、无线调试、Wi-Fi、蓝牙等系统页面。
- 保存常用网页入口，并按收藏顺序选择网页处理应用。
- 根据最近使用情况查找高频应用。
- 通过局域网管理固定应用、网页入口和系统设置快捷项。

## 系统要求

- Android 8.0 或更高版本。
- 高频应用功能需要用户手动授予“使用情况访问”权限。
- 局域网管理需要手机与访问设备处于可信的同一局域网。

## 使用方法

1. 安装并打开 Goto。
2. 点击右下角的“+”选择要固定的应用。
3. 点击“调整顺序”后拖动应用；轻点应用可确认移除，点击“完成”返回普通模式。
4. 按需启用系统设置快捷项，并添加常用网页。
5. 如需电脑管理，滚动到主页底部，在“局域网配置”中查看管理地址和访问口令。
6. 在同一局域网内访问 `http://<手机局域网 IP>:8787`，输入手机上显示的口令。

部分 Android 定制系统会在 Goto 首次启动其他应用时显示安全确认。确认应用来源和目标无误后，可按系统提示选择“始终允许”。这是系统的跨应用启动保护，不是 Goto 自行弹出的授权窗口。

## 权限说明

| 权限或能力 | 用途 |
|---|---|
| 网络与网络状态 | 提供局域网管理页面并显示当前访问地址 |
| 使用情况访问 | 读取近期应用使用频率；未授权时其他功能仍可使用 |
| 应用可见性 | 列出可启动应用及能够处理网页的应用 |

Goto 不需要通讯录、短信、电话、相机、麦克风或位置权限。

## 隐私与安全

- 配置保存在设备本地，项目不依赖远程账户或云端服务。
- 局域网服务器随 Goto 应用进程运行，退出进程后停止服务。
- 访问口令只提供局域网内的基础防护，请勿将端口映射或暴露到公网。
- 请只在可信网络中使用局域网管理功能，并在需要时重置访问口令。

## 应用信息

- 应用名称：Goto
- Android 包名：`cn.y10n.goto`
- 局域网管理端口：`8787`
